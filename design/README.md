# Diseños de referencia

Tableros exportados del canvas de diseño. Cada archivo `*.dc.html` es una pantalla a 390 px (mobile) o 1440 px (desktop/panel).
Son referencia visual, no código de producción: usan un runtime propio del canvas (`support.js`), así que no se abren directo en el navegador.
Leelos para copiar layout, tipografías (Google Fonts), colores, textos y orden de bloques.

Pantallas clave:
- `Jerarquia.dc.html` — orden de bloques de la página del invitado.
- `Confirmacion.dc.html` — flujo de confirmación (4 pantallas).
- `Regalos.dc.html` — lista de regalos mobile.
- `Pago.dc.html` — checkout del invitado (4 pantallas).
- `Personalizar.dc.html`, `ConfigRegalos.dc.html` — panel del organizador.
- `Tono.dc.html` — tono de voz.
- `Paletas.dc.html` — paletas de los estilos minimal.
- Estilos: `Foto*`, `Linea*`, `Torta*`, `Paisaje`, `Susurro`, `Firma`, y el resto.
